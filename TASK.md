# Задача и методика

Цель: подготовить подробные проверочные вопросы на русском языке по всем סימנים 70–100 включительно оригинального «קיצור שולחן ערוך» р. Шломо Ганцфрида и единый PDF без ответов.

Для каждого סימן сначала сверяется номер и полный текст на иврите, определяется перечень סעיפים, затем по каждому סעיף составляются вопросы о правилах, условиях, исключениях, мерах, временных границах и практических различиях. Переводы служат лишь вспомогательной сверкой. В файл главы включается служебная карта «סעיף → вопросы»; каждое существенное правило должно проверяться. Служебная часть исключается из сборки.

Порядок: строго 70→100. После полной проверки главы файл chapters/NNN.md сохраняется и публикуется; лишь после этого номер отмечается завершённым в progress.json. Допустим один атомарный commit файла и checkpoint. При возобновлении сравнить TASK.md, progress.json, фактические файлы и последние commits; сомнительные или оборванные главы не считать завершёнными. Готовые главы не переписывать без причины. GitHub — единственный долговременный источник состояния.

После 31 главы провести общий аудит полноты и точности, собрать build/combined.md без INTERNAL, затем output/kitzur-shulchan-aruch-questions-70-100.pdf. PDF: титульный лист, оглавление, заголовки, номера вопросов и страниц, хорошие поля, кириллица и иврит без дефектов. Визуально проверить начало, промежуточные и последние страницы, страницы с ивритом; только затем пометить pdf_verified.
