## Дополнительные вопросы и исследования

Файлы `chapters/NNN.md` — **единая точка входа для всех вопросов данного симана**: как исходных проверочных вопросов, так и добавленных при изучении. Новые вопросы сохраняются в соответствующем файле без изменения ранее составленного списка и контрольной карты покрытия.

Сложные темы получают самостоятельные заметки в [`research/`](research/), но **ссылка на исследование находится непосредственно в файле соответствующего симана**. Исследовательские заметки могут содержать подробный анализ и первоисточники; отсутствие результата помечается явно.

Дополнительные вопросы из личных записей внесены 12.10.2026. Исходные идентификаторы вопросов сохранены для проверки переноса; номера 3а и 3б различают два исходных пункта с одинаковым номером.

**Версии сборки:** `build/combined.md` и PDF в `output/` пока представляют прежний проверочный сборник без добавленных вопросов. Они не считаются обновлёнными до отдельной пересборки и проверки. Первичный актуальный перечень теперь находится в `chapters/`.
