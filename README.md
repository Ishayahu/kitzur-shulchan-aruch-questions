Работа идёт в порядке 70–221, затем 1–69; итоговый документ будет расположен в порядке 1–221. Отдельные главы находятся в `chapters/`, текущее состояние — в `progress.json`, методика — в `TASK.md`. После завершения итоговый PDF будет в `output/kitzur-shulchan-aruch-questions-1-221.pdf`.
